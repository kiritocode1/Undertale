# Undertale: Game of Life, Reimagined

This project is a playful, interactive twist on the classic "Game of Life." Here, users can upload their own images, which are then transformed into dynamic canvases—bringing personal photos to life within the simulation.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

To start exploring, upload an image of your choice. The app will convert your photo into a pixelated canvas and animate it using Game of Life rules, creating a unique, evolving pattern from your image.

You can begin editing the main page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a modern font family from Vercel.
